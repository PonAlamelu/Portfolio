# Ponalamelu S — Developer Portfolio

A premium, highly animated, and modern developer portfolio website designed with a sophisticated dark-neon SaaS aesthetic. Built using vanilla web technologies, optimized for performance, responsiveness, and interactive user experience.

🚀 **Live Demo:** [Open Portfolio](index.html)

---

## ✨ Features

- **🌌 Dark-Neon Aesthetic:** A sleek space-black background (`#030712`) accented with glowing neon-blue and violet backdrops.
- **✨ Ambient Particle Background:** Lightweight HTML5 `<canvas>` rendering delicate floating star dust particles.
- **⚛️ Floating Technology Badges:** Independent floating React, Node.js, MongoDB, and JavaScript badges with custom keyframe animations and pulsing glows.
- **🖱️ 3D Parallax Tilt:** Dynamic interactive 3D perspective shift on the profile photo card relative to cursor movement.
- **⌨️ Typewriter Intro:** Smooth terminal-style typewriter animation revealing the developer subheader.
- **📂 Glassmorphic Detail Modals:** Interactive project modals loading fully structured write-ups for featured works.
- **📱 Smooth Scroll Reveals:** Experience timeline cards and education blocks slide into viewport dynamically from alternating sides.
- **🛠️ 100% Monolithic & Optimized:** Handcrafted vanilla CSS and JS compiled into a single file structure for instant loading.

---

## 🛠️ Built With

- **HTML5** & **Semantic Markup**
- **Vanilla CSS3** (Custom Properties, Flexbox, CSS Grid, Advanced `@keyframes`)
- **Vanilla JavaScript** (IntersectionObserver API, HTML5 Canvas API, Mouse-tracking Parallax)
- **Google Fonts** (Sora, Inter, JetBrains Mono)
- **SVG Vector Graphics**
